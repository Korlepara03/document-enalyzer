# Job Description – AI Engineer

## Position: AI Engineer

### Job Summary
We are looking for an **AI Engineer** to design, develop, integrate, and deploy AI-powered solutions using **Python and relevant AI/ML technologies**. The ideal candidate should have strong programming skills, practical knowledge of machine learning and deep learning, and the ability to convert business requirements into scalable AI solutions.

### Key Responsibilities
- Design and develop AI/ML solutions using **Python**.
- Build, train, evaluate, and optimize machine learning and deep learning models.
- Develop AI applications using frameworks such as **PyTorch, TensorFlow, Scikit-learn, and Hugging Face**.
- Perform data preprocessing, feature engineering, model selection, and performance evaluation.
- Develop **REST APIs** to integrate AI models with web and enterprise applications.
- Build backend services using **FastAPI, Flask, or Django**.
- Work with **Generative AI, LLMs, NLP, Computer Vision, and AI agents** where applicable.
- Implement Retrieval-Augmented Generation (RAG), embeddings, vector databases, and prompt engineering for GenAI applications.
- Integrate AI solutions with databases such as **MySQL, PostgreSQL, MongoDB, or SQLite**.
- Containerize and deploy AI applications using **Docker** and cloud platforms such as **AWS, Azure, or GCP**.
- Implement testing, monitoring, logging, and performance optimization for AI applications.
- Use **Git and GitHub/GitLab** for version control and collaborative development.
- Develop end-to-end AI solutions from **data ingestion and model development to API integration, UI integration, deployment, and monitoring**.
- Create technical documentation, test cases, and model evaluation reports.
- Collaborate with data scientists, software engineers, product teams, and business stakeholders.

The AI Engineer should be capable of taking an AI requirement from **idea → data → model → API → application/UI → testing → deployment → monitoring**, while maintaining scalability, security, reliability, and maintainability.
